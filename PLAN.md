# screenpen: план

Rust-порт [ScreenInk](https://github.com/volyx/ScreenInk) (порт согласован с автором):
overlay для рисования поверх экрана на презентациях, демо и записи экрана.
Формат плана по мотивам [obra/superpowers](https://github.com/obra/superpowers) (MIT).

## Решения

| Тема | Решение |
|---|---|
| Цель | OSS под MIT для себя, подпись exe и нотаризация позже |
| Платформы | Windows 11 x64, затем macOS arm64, затем Linux (X11/Wayland) |
| Окна | свой platform-слой: `windows` (windows-rs), позже `objc2` |
| Рендер | CPU, `tiny-skia`, перерисовка только dirty-областей |
| Вывод | `UpdateLayeredWindow` с premultiplied BGRA |
| Текст | `cosmic-text`, простой ввод без IME |
| Ввод | `WM_POINTER` с первого дня, давление пера отдельной фазой |
| Палитра | отдельное owned-окно, рисуем сами в tiny-skia; иконки с подсказкой «название + клавиша»; двигается за ручку, двойной клик поворачивает, прилипает к краям |
| Настройки | отдельное окно на egui из трея: шорткаты, состав и порядок палитры, цвета; применяются сразу |
| Шорткаты | переназначаются все (глобальные и однобуквенные), пустая привязка = выключен, конфликты подсвечиваются |
| Шпаргалка | «?» или кнопка палитры, карточка поверх экрана, скрыта из захвата |
| Язык | RU + EN по языку системы, переключатель в настройках |
| Захват | палитру можно скрыть из трансляции (`WDA_EXCLUDEFROMCAPTURE`), переключатель в трее |
| Хоткеи | Ctrl+Alt+Shift+A рисование, Ctrl+Alt+Shift+G выход из ghost, G вход, Ctrl+Alt+Shift+Q выход |
| Трей | иконка цвета режима, ЛКМ рисование, ПКМ меню, уведомление при старте, один экземпляр |
| Релизы | каждая сборка на проверку = тег `vX.Y.Z-alpha.N`, exe в GitHub Releases |
| Фокус | overlay забирает фокус, PgUp/PgDn/стрелки пересылает в прошлое окно |
| Модификаторы пера | Ctrl прямоугольник, Ctrl+Alt эллипс, Alt стрелка, Shift ограничение |
| Настройки | TOML в `%APPDATA%\screenpen`, автозапуск через `HKCU\...\Run` |

Из markeron (MIT) берём: `WS_EX_TOOLWINDOW` (иначе видео в браузере под окном
чёрное), окно на 1px ниже монитора (иначе Win11 считает его fullscreen и ломает
таскбар), позиция и размер одним `SetWindowPos`. Не берём: WebView, авто-ghost при
потере фокуса, overlay только на одном мониторе.

## Структура

- `crates/screenpen-core`: модель, геометрия, undo, растеризация в tiny-skia.
  Без зависимостей от ОС, всё покрыто тестами, собирается и тестируется на Linux.
- `crates/screenpen`: приложение. `src/platform/<os>/` окна, ввод, хоткеи, трей.
- Поток данных как в ScreenInk: ввод → инструмент → мутация `Document` (снимок
  в undo) → перерисовка. Инструменты трогают только bitmap живого штриха.
- Координаты: физические пиксели монитора, начало сверху слева.

## Фазы

Статус ведём здесь же, после каждой фазы.

**Фаза 0. Спайк overlay на Windows.** Снимает главный риск стека.
- Окно на каждый монитор: layered, topmost, toolwindow, per-monitor DPI v2.
- Глобальный хоткей, рисование мышью полилинией через tiny-skia, Esc, ghost mode.
- Пересылка PgUp/PgDn/стрелок в предыдущее окно.
- Тестовое owned-окно палитры с переключением `WDA_EXCLUDEFROMCAPTURE` по F9.
- *Готово, когда* на твоей Win11 пройден чек-лист ниже.

**Фаза 1. Порт core.**
- Annotation, Style, Document (+undo), StrokeBuilder, PressureFilter, StrokeOutline,
  Tools, Shortcuts, рендер аннотаций в tiny-skia.
- Тесты ScreenInk переносятся один в один, плюс self-test: рендер всех видов
  аннотаций в PNG (CI на Linux).
- *Готово, когда* `cargo test` зелёный, PNG self-test совпадают с ожиданием на глаз.

**Фаза 2. Инструменты на Windows.**
- Bitmap-кэш живого штриха, все инструменты, выделение, ластик, текст.
- Модификаторы пера, ПКМ ластик, Ctrl+колесо толщина, W доска, затемнение,
  автозатухание.
- *Готово, когда* все инструменты работают на всех мониторах, undo после любого действия.

**Фаза 3. Палитра, настройки, шорткаты.**
- Палитра с иконками и подсказками, ручка, поворот, прилипание, позиция запоминается.
- Окно настроек на egui: шорткаты (запись, выключение, конфликты, сброс), состав и
  порядок палитры, цвета, язык. Хранение в TOML, применение на лету.
- Шпаргалка по «?». Трей: затемнение, автозатухание, автозапуск, настройки.
- i18n RU/EN.

**Фаза 4. Ghost mode и полировка Windows.**
- Подключение/отключение мониторов без потери рисунков, смешанный DPI.
- Поверх fullscreen: детект чужого окна без `WS_CAPTION` во весь монитор.
- Релиз: zip с exe из CI (без подписи, SmartScreen предупредит).

**Фаза 5. macOS.** NSPanel non-activating, уровень screenSaver, все Spaces,
вывод через CALayer contents, Carbon hotkey.

**Фаза 6. Linux.** X11 и Wayland (layer-shell где есть).

**v2:** spotlight, лупа, freeze, снапшоты, экспорт PNG/PDF, давление пера, лазер.

## Чек-лист фазы 0 (руками на Win11)

1. Ctrl+Alt+Shift+A показывает overlay на всех мониторах, рисуется мышью, Esc прячет.
2. Поверх браузера в F11 и PowerPoint Slide Show (в том числе на втором мониторе).
3. В Slide Show PgDn/стрелки листают слайды, рисунок остаётся.
4. Рисунок виден в демонстрации экрана Teams/Zoom/OBS; палитра после F9 не видна.
5. G включает ghost: клики проходят в окно под overlay. Ctrl+Alt+Shift+G возвращает рисование.
6. Мониторы с разным масштабом (100% и 150%): линия идёт ровно под курсором.
7. Видео в браузере под overlay не чернеет, таскбар не меняет вид.

## Проверки

- `cargo test --workspace` и `cargo clippy --workspace -- -D warnings` (Linux).
- `cargo check --target x86_64-pc-windows-msvc -p screenpen` на VM.
- CI: Linux тесты + self-test, Windows сборка exe в артефакт.

## Откат

Если фаза 0 покажет, что layered-окно не перекрывает Slide Show или не попадает
в захват, пробуем DirectComposition-окно (`WS_EX_NOREDIRECTIONBITMAP`) с тем же
tiny-skia-буфером. Core от этого не меняется.

## v2: остаток (2026-10-26)

1. Экспорт в PDF (`screenpen-core::pdf`): аннотации векторами (те же `render_parts`), фон
   картинкой (FlateDecode через miniz_oxide), прозрачность через ExtGState.
2. Снимки с восстановлением (`crates/screenpen/src/snapshots.rs`): Ctrl+S пишет
   `Изображения/screenpen/<имя>.png` (экран с рисунком) и рядом `.screenpen/<имя>.json`
   (аннотации, размер и масштаб экрана) + `.screenpen/<имя>.background.png` (экран без рисунка).
   Восстановление = заморозка с сохранённым фоном + аннотации одним шагом undo.
3. Галерея: вкладка «Снимки» в окне настроек (миниатюры, восстановить, PDF, удалить,
   папка). Запрос на восстановление идёт в основной процесс файлом `restore.request`
   рядом с настройками + существующий сигнал перечитать настройки.
4. Лупа (M): Windows через Magnification API с исключением наших окон, macOS через
   CGWindowListCreateImage ниже наших панелей, Linux недоступна (X11 захватывает саму
   линзу, Wayland не даёт захват): кнопка неактивна, в логе причина.
*Готово, когда* всё собирается под три ОС, тесты на PDF/снимки зелёные, скриншоты галереи
под Xvfb проверены глазами.

2026-10-26: остаток v2 сделан. PDF (`screenpen-core::pdf`, тест на xref), снимки с данными
и чистым фоном, восстановление (вкладка «Снимки», `--restore`, запрос файлом + сигнал
перечитать настройки; проверено под Xvfb на Linux), лупа M: Windows через Magnification

## v3: дизайн и UX для всех (2026-10-27)

Цель: понятный с первого раза инструмент, который можно раздавать коллегам. Обзор аналогов
(ZoomIt, Epic Pen, gInk/ppInk, Presentify, ScreenBrush, DrawPen, Zoom, Excalidraw, tldraw,
Figma) лежит вне репы, в `~/Work/screenpen-research/analogs.md`; макет там же, `mockup.html`.

1. Текст как обычное поле ввода (`screenpen-core::text_edit`): курсор, стрелки, Home/End,
   слова через Ctrl (Option на Mac), Shift выделяет, мышь ставит курсор и выделяет, двойной
   клик выделяет слово, Ctrl+A/C/X/V через arboard, Ctrl+Z/Y внутри текста, Ctrl+Enter.
2. Палитра: группы через разделители, «Мышь» первой кнопкой (бывший режим призрака),
   фигуры одной кнопкой со строкой видов, строка текста (размер, B, I), редкое под «⋯»,
   6 цветов, толщина S/M/L, буква клавиши в углу кнопки, подсказка с плашкой клавиши.
   Тёмная, светлая или системная тема. По умолчанию внизу по центру; старые палитры
   заменяются один раз (`palette.version`), нетронутые цвета переставляются.
3. Шпаргалка по группам с плашками и блоком «Пока печатаете».

## Магнит (2026-10-27)

С Ctrl фигуры (прямоугольник, эллипс, линия, стрелка, Ctrl-фигуры пера) липнут к краям окон,
панелей и кнопок; Ctrl+клик без перетаскивания обводит блок под курсором, пунктир показывает
его заранее. Края ищутся на снимке экрана (`screenpen-core::snap`): длинные непрерывные
перепады яркости, ~8 мс на Full HD. Снимок берётся при первом Ctrl и забывается при показе
и выходе из режима мыши; замороженный экран отдаёт свой. Пример `snap` рисует найденное на
PNG. На macOS нужно разрешение записи экрана, на X11 рисунок моргает при снимке, на
нативном Wayland магнита нет.

Проверить руками: Ctrl+наведение на окно/панель (пунктир), Ctrl+клик пером (рамка),
Ctrl+перетаскивание прямоугольника к краю (голубые направляющие), то же при заморозке (F),
задержку при первом Ctrl на 4K.
